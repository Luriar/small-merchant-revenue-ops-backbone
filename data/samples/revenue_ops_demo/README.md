# Revenue Ops Demo Sample Data

**이 디렉토리의 모든 파일은 데모 목적의 합성 샘플 데이터입니다.**
실제 공공 API에서 수집한 데이터가 아닙니다.
수치는 시나리오 시뮬레이션을 위해 임의로 생성되었습니다.

## 시나리오

- 지역: 서울 / 성수 (Seongsu)
- 업종: 카페/커피음료
- 기준 기간: 2024 Q3 (2024년 7월-9월)
- 비교 기간: 2024 Q4 (2024년 10월-12월)
- 매출 변화: 약 -12%
- 거래건수 변화: 약 -10%
- 유동인구 변화: 약 -8%
- 강수일 증가, 점포수 증가
