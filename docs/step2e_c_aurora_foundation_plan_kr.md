## 7. Cost Notes

Aurora plan introduces recurring cost:

- Aurora PostgreSQL Serverless v2
- one `db.serverless` cluster instance
- min capacity `0.5` ACU
- max capacity `1` ACU
- database storage and backup storage
- PostgreSQL CloudWatch log export
- Secrets Manager secret

This is the minimum modeled dev/prod-min Aurora shape, but it is not free. Apply should happen only after explicit approval of ongoing Aurora cost.

## 8. Security Notes

Modeled controls:

- DB is placed in the dedicated Revenue Ops private subnets.
- Cluster storage encryption is enabled.
- Deletion protection is enabled.
- Backup retention is `7` days.
- Master password is generated and stored in Secrets Manager.
- DB ingress allows TCP 5432 from Lambda SG `sg-0f269d20c37ea2f15`.
- API JWT enforcement remains disabled.

Review note:

- The Aurora module currently creates a separate DB security group in addition to the network foundation Aurora SG.
- The module-created DB SG is the one attached to the cluster in this plan.
- This is safe from a least-access standpoint because ingress is still SG-scoped to the Lambda SG, but it leaves the network foundation Aurora SG unused for the cluster unless the module is later refactored to accept an existing SG.
