# M2-2 Evidence Review Checklist

Review safe evidence only.

- [ ] field-name sets recorded.
- [ ] sampled message counts recorded.
- [ ] topic names recorded.
- [ ] publication table membership recorded.
- [ ] allowed column names recorded.
- [ ] yes/no leakage result recorded.
- [ ] `op`/`ts_ms` presence result recorded.
- [ ] DELETE primary-key presence result recorded.
- [ ] `_deleted` mapping result recorded.
- [ ] slot lag summary recorded.
- [ ] cleanup status recorded.
- [ ] No raw payloads recorded.
- [ ] No full message bodies recorded.
- [ ] No secrets, DB URLs, endpoints, account IDs, SecretString, tokens, passwords, or raw connection strings recorded.
- [ ] No issue title/body/payload/reporter values recorded.
- [ ] No prod_change payload/actor values recorded.
- [ ] No screenshots or logs exposing raw values recorded.
